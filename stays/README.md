# Property photos

Drop a jpg here named after the property and `stays.html` picks it up automatically —
no code change. The page renders a "see photos" placeholder until the file exists.

| Filename | Property |
|---|---|
| `pods.jpg` | Lima Airport Sleeping Pods |
| `rupa-rupa.jpg` | Rupa Rupa High Jungle Eco B&B, Aguas Calientes |
| `aranwa.jpg` | Aranwa Cusco Boutique Hotel |
| `indigo.jpg` | Hotel Indigo Lima Miraflores |

Cards are 16:7, so roughly 1200×525 looks right. Keep each file under ~300 KB.

These are property photos owned by the hotels or the booking sites. This repo is public,
so prefer a photo you took, or one the property publishes for guest use.
